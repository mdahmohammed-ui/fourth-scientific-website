# مشروع الرابع العلمي — الموقع + API + بوت تيليجرام

مشروع واحد يحتوي على موقع عربي متجاوب، وواجهة API، وبوت تيليجرام. **الموقع والبوت يقرآن ويكتبان في قاعدة البيانات نفسها**؛ إذا أضيف ملف من لوحة البوت يظهر بالموقع، وإذا عُدّلت بياناته أو أُخفي، يتحدث العرض من القاعدة المشتركة.

## ما الذي يتضمنه المشروع؟

- أقسام المحتوى: الكتب، الملازم، الملخصات، الامتحانات.
- المواد المبدئية المتفق عليها: الرياضيات، الكيمياء، الفيزياء، الأحياء، English، التربية الإسلامية، الحاسوب، الكردي، اللغة العربية، جرائم حزب البعث.
- بحث بحسب اسم الملف أو المادة أو المدرّس أو الوصف، وتصفية بحسب القسم والمادة.
- الوضع الليلي، أحدث الملفات، الأكثر استلامًا عبر البوت، وحفظ الملفات على جهاز الطالب.
- جدول مذاكرة محلي على جهاز الطالب (لا يحتاج حسابًا، ولا تتم مزامنته بين الأجهزة).
- طلب ملزمة/ملف يحفظ الطلب في قاعدة البيانات ويرسل تنبيهًا للمالك إذا كان البوت شغالًا.
- معاينة صورة الامتحان عند رفعها للبوت. ملفات PDF لا تُعرض داخل الموقع ولا يُقدّم الموقع رابط تنزيل مباشر لها؛ زر الاستلام يفتح `@YIFiabot` برابط `start=file_ID`، والبوت يرسل الملف.
- لوحة مالك داخل البوت: إضافة وتعديل واستبدال وحذف وإخفاء/إظهار الملفات، إدارة المواد، إدارة الملخصات، الطلبات، الإحصائيات، الإعلانات، وإعدادات البوت.
- لوحة إدارة للموقع على `/admin.html` محمية بمفتاح `ADMIN_API_KEY`، لإدارة المواد والملفات والإعدادات والطلبات.
- تحقق الاشتراك الإجباري من `@Kii_8i` في البوت، مع استثناء المالك `7683201905`.
- لا توجد ملفات دراسية وهمية مضافة مسبقًا. الملفات تظهر بعد رفعها فعليًا.

## تشغيل محلي على الكمبيوتر

1. ثبّت Python 3.11 أو 3.12.
2. من مجلد المشروع أنشئ بيئة افتراضية وثبّت المتطلبات:

   ```bash
   python -m venv .venv
   # Windows: .venv\\Scripts\\activate
   # Linux/macOS: source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. انسخ `.env.example` إلى `.env`، ثم اضبط المتغيرات. لا ترفع ملف `.env` إلى GitHub.
4. شغّل التطبيق:

   ```bash
   uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
   ```

5. افتح `http://127.0.0.1:8000`. لوحة الإدارة `http://127.0.0.1:8000/admin.html`.

> عند ترك `DATABASE_URL` فارغًا، يُستخدم SQLite محليًا داخل مجلد `data`. عند النشر استخدم PostgreSQL مُدارًا، لأن القرص المحلي في كثير من خطط الاستضافة المجانية قد لا يحتفظ بالبيانات بعد إعادة التشغيل أو إعادة النشر.

## متغيرات البيئة المطلوبة للنشر

| المتغير | القيمة |
|---|---|
| `BOT_TOKEN` | توكن البوت من BotFather — سرّي ولا يوضع داخل الكود |
| `BOT_USERNAME` | `YIFiabot` دون `@` |
| `OWNER_ID` | `7683201905` |
| `MANDATORY_CHANNEL` | `@Kii_8i` |
| `SITE_URL` | رابط الموقع الكامل بعد نشره، ويبدأ بـ `https://` |
| `ADMIN_API_KEY` | مفتاح إداري طويل وعشوائي، مختلف عن توكن البوت |
| `DATABASE_URL` | رابط قاعدة PostgreSQL من مزوّد قاعدة البيانات |

يجب إضافة البوت مشرفًا في قناة `@Kii_8i` حتى يستطيع فحص العضوية. لا تضع توكن البوت أو مفتاح الإدارة في ملف JavaScript أو HTML.

## النشر باستخدام GitHub وRender

1. ارفع **محتويات هذا المجلد** إلى مستودع GitHub الذي أنشأته، وليس ملف ZIP فقط.
2. أنشئ قاعدة PostgreSQL من مزوّد مثل Neon وانسخ رابط الاتصال الخاص بها في `DATABASE_URL`.
3. أنشئ Web Service من مستودع GitHub. أمر البناء: `pip install -r requirements.txt`، وأمر التشغيل: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`.
4. أضف متغيرات البيئة أعلاه في إعدادات الخدمة. لا تترك `BOT_TOKEN` أو `ADMIN_API_KEY` فارغين إذا تريد تفعيل البوت ولوحة الإدارة.
5. بعد ظهور رابط الموقع، أضفه إلى `SITE_URL` وإعدادات البوت المشتركة. أعد تشغيل الخدمة.
6. اختبر `/health`، ثم افتح الموقع وجرّب `/admin.html`، وبعدها أرسل `/start` للبوت.

**ملاحظة استضافة:** خطة Render المجانية قد توقف الخدمة بعد عدم النشاط؛ لذلك لا يوجد ضمان أن البوت سيبقى متصلًا 24/7 على خطة مجانية. يلزم التحقق من شروط الاستضافة الحالية قبل الاعتماد عليها، وقد تحتاج خطة لا تنام أو خدمة منفصلة للبوت.

## طريقة إضافة ملف عبر البوت

1. افتح البوت بحساب المالك ثم اختر «لوحة المالك» أو اكتب `/admin`.
2. اختر «إضافة ملف»، ثم النوع، ثم المادة.
3. أرسل ملف PDF كـ Document، وأكمل الاسم والمدرّس والوصف وسنة الإصدار.
4. إذا كان النوع امتحانًا، أرسل صورة المعاينة أو اكتب `-` لتخطيها.
5. يؤكد البوت رقم الملف ورابط استلامه. لا يحتاج الطالب إلى معرفة `file_id`؛ معرف تيليجرام يبقى في قاعدة البيانات ولا يظهر للعامة.

## API المتاحة

- `GET /health`
- `GET /api/meta`
- `GET /api/subjects`
- `GET /api/files?category=books&q=فيزياء&sort=latest`
- `GET /api/files?sort=popular`
- `GET /api/stats`
- `POST /api/requests`
- لوحة إدارة محمية بـ `X-Admin-Key`: المسارات تحت `/api/admin/...`

## حدود يجب معرفتها

- كود المشروع جاهز للتشغيل، لكن الربط الحي لا يمكن التحقق منه قبل وضع توكن البوت ورابط قاعدة البيانات ونشر الخدمة.
- لا يمكن ضمان «99.9% خالٍ من الأخطاء» قبل التشغيل في بيئة النشر الفعلية. تمت إضافة اختبارات أساسية، ويجب تجربة الإضافة والاستلام والاشتراك الإجباري بعد إعداد الأسرار.
- لا يضيف المشروع أي ملفات كتب أو ملازم من تلقاء نفسه؛ يجب أن ترفع ملفاتك الحقيقية عبر لوحة البوت.
